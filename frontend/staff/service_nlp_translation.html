About Neural Translation API
Dịch vụ AI Neural Machine Translation cung cấp khả năng chuyển đổi ngôn ngữ tốc độ cao, giữ nguyên ngữ cảnh chuyên ngành, văn phong tự nhiên. Hệ thống được tối ưu hóa cho cặp ngôn ngữ Tiếng Việt ↔ Tiếng Anh, cùng các cặp ngôn ngữ quốc tế phổ biến (Nhật, Hàn, Trung, Pháp, Đức).
Key Features
  • Dịch thuật ngữ cảnh sâu: Áp dụng mô hình Neural Transformer chuyên trách giữ trọn cấu trúc câu.
  • Độ trễ cực thấp: Tối ưu CTranslate2 int8 inference tăng tốc độ xử lý gấp 4 lần.
  • Đa dạng cặp ngôn ngữ: Hỗ trợ dịch hai chiều Tiếng Việt, Tiếng Anh, Tiếng Nhật, Tiếng Hàn, Tiếng Trung...
  • Tích hợp dễ dàng: REST API chuẩn OpenAPI, SDK Python/cURL/PHP hỗ trợ sẵn.
