Text to Speech API
Free remain: 100,000 characters / year
Introduction

Everwin AI Text to Speech (TTS) API provides ultra-realistic Vietnamese voice synthesis powered by state-of-the-art viXTTS neural models across North, Central, and South regional accents.

Applications

This API powers voice applications including:

  • Automated Voice Broadcast & IVR: Enterprise telemarketing, automated customer notifications, and call centers.
  • Audiobooks & News Readers: Converting digital articles and literature into expressive natural audio.
  • Smart Devices & Assistants: Adding natural Vietnamese voice feedback to IoT devices.
You need to enable this api to run demo
API Endpoint & Request URL
POST https://ai-platform-6p72.onrender.com/v1/audio/speech
Request Headers & Parameters
Parameter Required Default Description
api_key YES None Your API Key (Get from Developer Console).
voice NO banmai Identify the voice: banmai (female northern), lannhi (female southern), leminh (male northern), myan (female middle), thuminh (female northern), giahuy (male middle), linhsan (female southern).
speed NO 0 Adjust speed of the voice: +3 (fastest), 0 (normal), -3 (slowest).
format NO mp3 Identify output format: mp3 or wav.
callback_url NO None URL provided by customer to receive async notification when sound is ready.
Request Body & Limit

Contains raw text to convert into speech.
Note: Limit per request: 5,000 characters. Minimum request length: 3 characters.

Sample Response (Success JSON)
