Introduction

Speech synthesis & recognition is the fundamental component of modern artificial intelligence systems. With high ambition, Everwin Technology Innovation Department has launched Everwin AI Speech Synthesis & PhoWhisper ASR. Considered as the best integrated system of Vietnamese language voice processing in the market today, Everwin's new Vietnamese Speech API is open for evaluation on enterprise cloud infrastructure.

Applications

This API has been applied across critical enterprise use-cases:

  • Building automatic communication systems: Automated AI call centers, virtual agents, self-service kiosks, maid robots.
  • Enhance user experience: Reading content for users when unable to monitor screen, voice-enabled reading applications.
  • Accessibility services: Language interaction and screen-reading services for visually impaired people.

API Endpoint & Request URL
POST https://ai-platform-6p72.onrender.com/v1/audio/speech
Request Headers & Parameters
Parameter Required Default Description
api_key YES None Your API Key (Get from Developer Console).
voice NO banmai Identify the voice: banmai (female northern), lannhi (female southern), leminh (male northern), myan (female middle), thuminh (female northern), giahuy (male middle), linhsan (female southern).
speed NO 0 Adjust speed of the voice: +3 (fastest), 0 (normal), -3 (slowest).
format NO mp3 Identify output format: mp3 or wav.
callback_url NO None URL provided by customer to receive async notification when sound is ready.
Request Body & Limit

Contains raw text to convert into speech.
Note: Limit per request: 5,000 characters. Minimum request length: 3 characters.

Sample Response (Success JSON)
