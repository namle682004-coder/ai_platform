SDK Integration Snippets

cURL Request Example

curl -X POST https://ai-platform-6p72.onrender.com/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "chat-general-standard",
    "messages": [{"role": "user", "content": "Xin chào FPT.AI Platform!"}]
  }'

Python SDK Example

from aip_sdk import AIPClient

client = AIPClient(base_url="https://ai-platform-6p72.onrender.com", api_key="YOUR_API_KEY")
response = client.chat.completions.create(
    model="chat-general-standard",
    messages=[{"role": "user", "content": "Xin chào!"}]
)
print(response.choices[0].message.content)
